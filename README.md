# Cookie Clicker TMA

Кликер в духе Cookie Clicker, сделанный как Telegram Mini App. Чистый HTML/CSS/JS, без сборки и зависимостей.

## Что внутри

- `index.html`, `style.css`, `game.js` — вся игра
- Клик по печеньке + сила клика от количества курсоров
- 8 видов зданий (курсор → лаборатория) с растущей стоимостью
- Апгрейды, открывающиеся по мере прогресса
- Золотые печеньки (бонус печенек или временное "безумие" x7)
- Офлайн-прогресс (пока пользователь не в игре, печеньки продолжают копиться, с кап на 8 часов и коэффициентом 0.5)
- Автосохранение: `Telegram.CloudStorage` (если бот открыт в Telegram и версия клиента >= 6.9) + резервная копия в `localStorage`
- Haptic feedback на клики/покупки через `Telegram.WebApp.HapticFeedback`
- Цвета берутся из темы Telegram (`--tg-theme-*`), с фоллбэком на тёмную тему по умолчанию

## Локальный запуск

```bash
cd cookie-clicker-tma
python3 -m http.server 8642
```

Открыть `http://localhost:8642`. Вне Telegram игра тоже работает — просто сохраняется только в `localStorage`.

## Как задеплоить и подключить к Telegram

Telegram Mini App должен открываться по HTTPS-адресу.

1. **Задеплоить статику** любым способом:
   - GitHub Pages (`Settings → Pages`, ветка с этими файлами)
   - Vercel/Netlify (просто перетащить папку или подключить репозиторий)
2. **Создать бота** через [@BotFather](https://t.me/BotFather) → `/newbot`.
3. Настроить Mini App:
   - `/newapp` (или `/mybots → выбрать бота → Bot Settings → Menu Button/Mini App`)
   - Указать HTTPS-адрес задеплоенной игры
4. Открыть бота в Telegram и запустить приложение через кнопку меню.
